# 🌑 LUNARXXIX

> An interactive cosmic experience built for the 29th night.

**LUNARXXIX** is a cinematic interactive web experience combining royal dark-fantasy visuals, moonlit environments, anime-inspired aesthetics, and game-like interactions.

## ⚔️ Features

* 🌑 Interactive moonlit environment
* 🌌 Cosmic particle effects
* ☁️ Atmospheric animated clouds
* 🏸 Badminton-inspired interaction
* ⚔️ Anime-inspired visual effects
* 🎮 Interactive elements
* 🎬 Cinematic animations and transitions
* 📱 Responsive design

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Three.js
* GSAP
* Vite

## 🎯 Purpose

LUNARXXIX was created as a personal interactive experience while exploring modern web development, animation, 3D graphics, and interactive design.

## 🚀 Status

**In development.**

More features and interactive elements will be added as the project evolves.
